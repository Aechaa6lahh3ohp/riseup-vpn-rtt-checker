# riseup-vpn-rtt-checker
## About
This Python script only measures RTT and has no other functionality.

## Use cace
Have `riseup-rtt.py` argment is `-u, --update` and `-b, --benchmark`.
- -u : Get to gateways.json
- -b : Start Riseup-VPN Server RTT measures
